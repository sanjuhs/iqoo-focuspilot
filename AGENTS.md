# Project instructions

Read instructions.md, plan.md, hackathon.md and docs/status.md before changing scope.
The user authorizes parallel agents; assign non-overlapping files.
Keep .env, API credentials, private phone captures, model weights and training data out of Git.
Keep total project/dependency/model storage within 15 GB; aim below 10 GB.
Do not claim on-device LLM, Snapdragon NPU, Office Kit integration, training success,
or mechanistic interpretability results without reproducible evidence.
The public hackathon guide restricts competition code to the event window. This
repository is pre-event preparation, development utilities and explicitly labelled
research prototypes, not an eligible submission. Keep prototypes under prototype/.
Do not quietly relabel pre-event implementation as event-written code. Event
competition code must be separately created in the allowed window unless the
organizers explicitly approve reuse.
The product uses opt-in observation and a simulated accountability balance.
Real payments, purchases, messages and destructive actions require explicit action-level confirmation.
Use official Android documentation for permission and background-service design.
Record limitations and completed verification in docs/status.md.
