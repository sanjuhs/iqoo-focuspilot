# Structured command feasibility

Separate pre-event research toward natural phone commands with checked arguments.
The installed v0.16 app keeps its original Qwen3.5-0.8B Q4_0, prompt, validator and
native runtime. This experiment executes no phone tool and trains no model.

The first 24-case cohort is **development only**. Root reviews all gold action/slots
before model output. Commit the actual command/native/data/evaluation sources and
protocol before one original-prompt and one structured-prompt capture. Preserve
every attempt and all rows, including failures; no post-output source/label repair
or hidden retry. Exact raw predictions, validator decisions, full-slot proposals,
losses, unknown behavior and runtime scope must be reported separately.

All raw requests, gold, prompts, capture and detailed decisions stay in ignored
build directories. Public aggregates record hashes/counts and limitations.
No development result alone qualifies app deployment or competition eligibility.
