# Prepared reviewed-action adapter

This source-only scaffold maps the frozen CompatibleUnitCommand's accepted,
bounded canonical slots to the existing Android action proposal type. It changes
no candidate behavior, app source, native runtime, prompt or phone state. It is
not integrated or tested yet; it can be considered only if the prospectively
frozen fresh pipeline qualifies and exact adapter/application checks pass.

Fast local and checked-model origins remain separate. Review revalidates the
original complete request and refuses edited commands or missing provenance.
The Android caller must still enforce its own foreground/request-epoch ownership,
explicit confirmation, permission checks and actual execution verification.
The adapter itself performs no Android operation, inference or persistence.

Status questions map to a local snapshot, not a generated answer or explanation
of a past nudge's cause. Model activations are available only for actual inference;
the fast path must clear any old activation display and label the local parser.
