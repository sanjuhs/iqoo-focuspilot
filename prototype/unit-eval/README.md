new unit-aware generation with the already recorded structured-seconds output on
the same 24 seen development cases. Reusing the reference avoids a redundant model
run. This is not fresh confirmation or a controlled timing comparison.

original request. All non-duration guards remain the existing immutable structured
validator. No post-output repair, omitted rows or hidden retries. Root freezes exact
sources, labels, units, reference capture, prompt/grammar and token counts before
