# Compatible command pipeline — v0.17 research

The app keeps Qwen3.5-0.8B Q4_0 and adds the exactly frozen, qualified combined
pipeline. Explicit Understand first checks a complete fast local proposal without
loading or calling the model. Otherwise the user manually loads Qwen and explicitly
requests one structured fallback. Fast and Qwen provenance are displayed separately;
Review and Confirm revalidate the original request, slots, epoch and foreground
ownership. Edits, cancellation and screen leave discard proposals and old traces.

The informed fresh synthetic host comparison improves complete proposals 4 → 19/50
with 15 gains/no losses; all 50 unsupported requests are refused. Coverage remains
limited: 31 supported refusals, Explain 0/8; model-only has one alarm regression.
These results are not new phone accuracy or NPU measurements. See
[the frozen experiment and independent replay](compatible-command-research.md).
